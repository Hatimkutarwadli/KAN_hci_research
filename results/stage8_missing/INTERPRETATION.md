# Stage 8 (additional): missing-data robustness - interpretation (SYNTHETIC data only)

Frozen models and checkpoints, no retraining, no preprocessing change. Gaps are injected into the reconstructed standardized values and the frozen `causal_ffill` (<=3 days, then 0) is re-applied. Calibration (CAL) was used to develop the analysis; TEST was evaluated once with the same code (59/59 scenario-replicates per split; control reproduces saved predictions to <=3.8e-6). Tables: `analysis/summary_test.md`, `analysis/summary_cal.md`; per-seed values `analysis/degradation_per_seed_*.csv`; paired participant bootstrap (seed 0, 200 draws) `analysis/bootstrap_test_seed0.csv`; figures `analysis/fig1-3`. Numbers below are TEST, % degradation vs the same model/seed control (+ = worse), ranges across the 8 models. CAL agrees in direction and rough size everywhere I checked (S1_r40, S2_r40_L7, S3_k14, S4_activity_absent, Z0, decomposition rows).

## Reduced temporal sampling (approved protocol)
Origins 27, 29, ..., 119 (47 per participant instead of 93), same for CAL and TEST, all participants/labels/seeds/replicates kept. Neighbouring origins are strongly correlated, so the effective sample is smaller than the row count suggests and metrics (especially onset AP, 32 onset participants in test) are noisier. Control and S1_r20 were recomputed on this origin set; the earlier full-origin pilot is in `_superseded_full_origin_timing_check/` and is not used anywhere.

## Findings
1. **Rate:** degradation grows monotonically with the missing rate. At 10-20% random daily loss (close to the baseline 15%) severity RMSE worsens by about 0-1.4% and onset AP changes are within noise (-5% to +4%). At 40-60% random loss severity worsens 2-10%.
2. **Contiguity matters more than rate:** 20% loss in 7-day blocks (S2_r20_L7) worsens severity RMSE 1.9-3.2% vs 0.3-1.4% for random 20%; onset AP +6 to +15%. Longer blocks (L14) are worse again.
3. **Trailing outage right before the prediction is the most damaging scenario.** S3_k14: severity RMSE +9 to +16%, onset AP +24 to +54%, onset AUROC +8 to +16%, status AP +20 to +29%. S3_k7: onset AP +15 to +40%. Bootstrap (seed 0): onset-AP drop CI excludes 0 for 6-8 of 8 models at S3_k7/k14; severity RMSE CI excludes 0 for all 8 models in nearly every scenario.
4. **Signal groups:** removing activity entirely is the largest single-group loss (severity +9.5 to +11%, status AP about +25 to +33%, onset AP +19 to +31%), then cardiac (severity +5 to +11%, onset AP +14 to +29%), then sleep (severity +4 to +7%, onset AP about unchanged or even lower). **Circadian absent has about zero effect (slightly negative)**: the models do not appear to use that channel for these tasks.
5. **Models:** all eight degrade in the same directions. Under trailing outage the recurrent/GRU-family models (GRU, KANGRU, KANGRU-fixed) lose most onset AP (+43 to +54%), the KAN/KAN-reg/M1-static models least (+24 to +31%); under activity absence the ordering reverses for some. Differences between models are often within the seed SD (SD up to 5-10 points for onset AP). **No model is claimed to be more robust**; this is descriptive and not a ranking.

## Physiological signal loss vs loss of informative missingness indicators
Variants: O = values lost but mask flags left as in the original data (signal loss only); H = frozen semantics (gaps flagged); H-O = effect of the flags changing; Z0 = flags zeroed with no data loss (informative indicators removed alone). Interactions are possible, so O + (H-O) = H exactly but Z0 is not additive.
- **Severity, random/blocked gaps:** the flag change is as large as or larger than the pure signal loss for several models. S1_r40: O +1.0 to +1.6%, H-O +0.6 to +3.1% (total +1.9 to +4.6%). S2_r40_L7: O +3.1 to +5.1%, H-O +0.3 to +3.8%.
- **Severity, trailing outage:** signal loss dominates (S3_k14: O +7 to +13%, H-O +1 to +5%).
- **Onset AP:** signal loss dominates (S3_k7 O +15 to +41%, H-O about 0); the flag effect is small and inconsistent in sign (e.g. S2_r40_L7 H-O is negative, -1 to -5%, for most neural models, i.e. flagging the gap helped).
- **Flags alone (Z0):** removing the informative flags worsens severity RMSE by 0.2-1.4% and changes onset AP by -6 to +7% (KAN +6.9%), so the models do use them, modestly.
- **Calibration shift (clear effect):** under honest random gaps the mean predicted onset probability rises (x1.18-1.22 at S1_r40 for the neural models; severity +0.4 to +0.5 points) while with original flags kept (S1_r40_O) it is x0.96-1.00 (+0.0 points), and with flags zeroed (Z0) it falls to x0.89-0.97. In the simulator, missingness is informative (miss_informative=0.5), so the models learned that a flagged gap signals higher risk; MCAR gaps raise the flag rate without a corresponding rise in risk, so predicted risk is inflated although ranking metrics barely change.

## Does this reveal a genuine weakness in the methodology?
Partly, in this synthetic setting:
- **Yes, two things.** (a) Sensitivity to a recent contiguous outage, mainly for onset ranking (AP -24 to -54% at 14 days), where the frozen pipeline fills at most 3 days and then inserts zeros (the standardized mean, not a neutral "unknown"). (b) Reliance on informative-missingness flags: the models are miscalibrated when missingness is not informative (MCAR). The cause is not tested here; the O/H/Z0 contrast only shows the flags drive the shift.
- **Not a weakness:** moderate random loss (<=20%) is tolerated; circadian loss is irrelevant.
- The informative missingness is built into the simulator, so (b) is a property of this synthetic world; whether real wearable data behave the same is unknown. No improvement experiment was run.

## Limitations
Synthetic data, one dataset and one frozen split; test had already been evaluated in earlier stages. MCAR injection only (no informative/MNAR injection beyond the existing one); signal groups are my assumption (activity, sleep, cardiac, circadian). Models were not trained for missingness robustness. GBT sees zeroed values through window features, so its handling of imputed values differs from the networks. GBT is one deterministic run (no SD). Bootstrap is seed 0 only, and 8 models x 10 scenarios x 3 tasks are uncorrected multiple comparisons. Onset AP is noisy (32 test onset participants, half the origins). Gap draws differ per split, so CAL/TEST differences partly reflect mask realisation. No clinical or causal claim.
