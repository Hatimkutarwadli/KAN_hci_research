# P1-3: KAN vs matched-parameter MLP control, and KAN interpretability (SYNTHETIC; EXTENSION, not part of the original six stages)

Code `extension_p13/{models_p13,run_p13,compare_p13,interpret_p13,summarize_interp_p13}.py`; tests `tests/test_p13.py` (9 pass); results `results/p1_kan_mlp_control/{b2_main,m1_all,comparison,interpretability}`. Full tables: `comparison/p13_comparison.md`, `paired.csv`, `cost_and_convergence.csv`, `interpretability/interpretability_tables.md`, figures `interpretability/fig_*.png`.

## Design (fixed in advance, nothing tuned)
- Every KAN layer (10 params per edge: base + 9 spline coefficients) is replaced by a 2-layer SiLU MLP with the same parameter count. Wiring, pooling, LayerNorms, latent transition, dep/anx heads, dropout and initial-state map are identical. Params: B2 KAN 29,336 vs MLP 29,327; M1 KAN 20,932 vs MLP 20,997 (GRU 10,864).
- Frozen data, preprocessing, splits, heads and `fit_nn` protocol; each control uses the config of the KAN it controls: B2 default (16 heads), B2 regularised (wd 1e-3, drop 0.3, as fixed in Stage 3b), M1 (28 heads, wd 1e-3, drop 0.3, as in Stage 4). 5 paired seeds. Existing KAN/M1/GRU results were reused, not retrained.
- Ablation: no-spline B2 (spline weights zeroed and frozen, so each edge is w*silu(x); 3,560 trainable params). Untrained (random-init) models are the null for the interpretability metrics. An association-only reference (no model) is also reported.
- The MLP is parameter-matched, not structure-matched (a KAN edge is a learnable univariate function; an MLP unit is not).

## A. Predictive performance (test; worse% of first vs second, NEGATIVE = first better; mean over seeds; n = seeds where first better)
| comparison | severity RMSE | status AP | sustained-onset AP | first-crossing AP | forecast sev / status AP |
|---|---|---|---|---|---|
| B2 MLP vs B2 KAN | +0.5 (2/5) | -0.7 ±9 (3/5) | +1.8 ±9 (2/5) | +1.8 (2/5) | n/a |
| B2-reg MLP vs KAN-reg | -0.4 (3/5) | +2.8 (2/5) | **+11.8 (0/5)** | **+9.6 (0/5)** | n/a |
| B2 no-spline vs KAN | **+1.7 (0/5)** | **+14.4 (0/5)** | +5.6 (2/5) | +9.7 (0/5) | n/a |
| M1 MLP vs M1 KAN | **-2.0 (5/5)** | **-7.5 (5/5)** | +0.8 (2/5) | **+6.8 (0/5)** | **-1.6 / -5.0 (5/5)** |
| B2 MLP vs GRU | +1.8 (0/5) | +2.6 (2/5) | +27.2 (0/5) | +20.1 (0/5) | n/a |
| M1 MLP vs GRU | +3.1 (0/5) | +5.2 (1/5) | +23.2 (0/5) | +13.0 (0/5) | +2.4 / +5.1 (0/5) |
(existing, same columns: B2 KAN vs GRU +1.3 / +3.0 / +25.5 / +18.4; M1 KAN vs GRU +5.3 severity, +11.7 status AP; all 0/5 seeds better than GRU except 2/5 for B2 status AP.)

1. **Plain B2: the matched MLP equals the KAN** (all differences inside seed noise; test and calibration disagree on sign for several groups). Replacing splines by an MLP neither helps nor hurts.
2. **Regularised B2: the KAN is better on sustained and first-crossing onset (AP +12%/+10% worse for the MLP, 0/5 seeds), although the MLP was nominally better on calibration** (calibration -7%): calibration-test disagreement; the test effect is the one reported but not decision-grade.
3. **M1: the matched MLP is better than the KAN version on severity (-2%), nowcast/forecast status AP (-5 to -8%), 5/5 seeds, but worse on first-crossing onset AP (+6.8%, 0/5).** So at matched parameters the KAN encoder/transition gives no across-the-board predictive advantage; the MLP version of M1 is better on 5 of the 8 reported groups (severity, status AP and AUROC, both forecast groups) and worse or equal on the other 3 (sustained-onset AP and AUROC, first-crossing AP).
4. **No-spline ablation:** removing the splines (leaving 12% of trainable parameters) costs +1.7% severity RMSE and +14% status AP, so the splines are doing useful work relative to a silu-linear unit, yet an equal-parameter MLP recovers the same performance. The advantage over no-spline is therefore **nonlinear capacity, not KAN-specific structure**.
5. **On the test split the GRU remains better than every variant in every group** (KAN, MLP and no-spline B2/M1 are all 1-5% worse on severity and 13-27% worse on sustained-onset AP); the MLP controls do not close the gap to the GRU, so the KAN-vs-GRU deficit reported earlier is not a KAN-specific penalty.

## Cost and convergence (CPU, 4 threads; existing runs were on a possibly different machine load, so wall times are approximate)
B2: KAN 472 CPU-s/seed vs MLP 64 (7x cheaper; best epoch 1.6 vs 1.0), no-spline 520 (same compute as KAN: the bases are still computed). M1: KAN 2,572 CPU-s/seed vs MLP 249 (10x cheaper). GRU 95. The unregularised B2 MLP and KAN both peak at epoch 1-2 and overfit afterwards (cal-loss rise after best +0.053 / +0.059); the regularised variants and M1 peak at 3-7 epochs (+0.005 to +0.010). No run hit the 25-epoch limit. KAN's extra cost buys nothing measurable in prediction here.

## B. Interpretability (calibration split, 2,000 fixed origins, window-shift response; recovery of the PLANTED effects sleep variability -> depression (+), steps -> depression (-), steps -> anxiety (-), HRV -> anxiety (-))
| model | sign accuracy (chance 0.5) | shape r with planted g | mean rank of planted channels among 8 (chance 4.5) | planted in top 3 (chance 0.375) |
|---|---|---|---|---|
| GRU, KAN, KAN-reg, no-spline, MLP, MLP-reg | 1.00 | 0.98-0.99 | 1.50 | 1.00 |
| M1 / M1-MLP | 1.00 | 0.99 | 1.70 / 1.65 | 1.00 |
| untrained nets (6 types) | 0.35-0.60 | -0.39 to 0.20 | 4.2-5.2 | 0.25-0.40 |
| association-only (no model) | all 4 signs correct | n/a | ranks 1, 2, 1, 3 by |r| | n/a |

1. **All trained models recover the planted signs and put the planted channels in the top 2-3 sensitivities, and they do so equally.** KAN vs matched MLP vs GRU differences are 0.000 in sign accuracy and rank (shape r differs by <=0.002; KAN vs no-spline +0.013). **KAN is not more interpretable than the equal-parameter MLP or the GRU on any of these measures.** Untrained networks stay near chance, so the metrics are not trivially satisfied.
2. **The recovery is not evidence beyond association.** A model-free correlation of channel window-means with severity gets all four signs right and ranks steps/HRV first. The data also contain the planted reverse paths (state -> steps, state -> HRV), dep-anx coupling and collinear channels (calories = 0.7 steps, circadian = -0.3 sleep variability). The models rank steps first for depression and for anxiety in 5/5 seeds (M1) or 0-5/5 seeds (B2 variants) for anxiety; for anxiety the first-ranked channel is steps or HRV depending on model/seed (HRV first in 4/5 KAN, 5/5 B2-MLP and 3/5 GRU seeds). Calories never outranks steps, but sleep variability is never the top channel for depression.
3. **Shape recovery is weak evidence.** The shape correlation of ~0.99 is almost guaranteed: any monotone curve, even a straight line, correlates 0.98-0.99 with tanh(c*x) on the +-2 SD grid. The window-shift responses (`fig_pdp_shapes.png`) are close to linear, and visibly less S-shaped than the planted bounded transform for all models; they do not demonstrate recovery of the saturation. The no-spline model and (at -2 SD) KAN and M1 show flatter negative tails, where the training data are sparse.
4. **KAN-native spline view** (`fig_kan_edges.png`): first-layer edge functions are smooth and mostly monotone for sleep variability, steps and HRV, but they differ in sign and size across encoder outputs, so a single "learned function per feature" does not exist; downstream layers recombine them. First-layer edge magnitude is nearly uniform across channels for B2 (share 0.09-0.11 each) and only moderately related to end-to-end sensitivity (Spearman 0.34-0.56 for B2 KAN, 0.87-0.89 for M1), so raw spline magnitude is a poor importance measure by itself.
5. **Lag structure:** the static B2 models (KAN and MLP) have a flat lag profile (mean pooling cannot localise lags), the recurrent models (GRU, M1, M1-MLP) weight recent days more (peak around lags 0-3 for sleep variability and steps; for HRV the GRU peaks at lag 0). The planted lags are 3 days (sleep variability), 2 (steps) and 1 (HRV) (CORRECTION: an earlier draft of this line said 1-2 days); the latent state integrates effects and features are autocorrelated, so this is not a lag estimate (see P1-4, which finds the lags are not recovered).
6. **No causal claim:** the responses show what the predictor learned from observational data in which state also drives features; they are not interventional effects. The planted structure is known only because the data are synthetic.

## Limitations
One synthetic dataset, 5 seeds, seed-0 bootstrap intervals only for the predictive comparison (in `p13_comparison.md`; many difference intervals overlap); calibration and test disagree for several effects (rely on sign consistency across seeds, treat effects below about 2% as not established); the MLP is parameter-matched with SiLU activations and a fixed bottleneck rule, other MLP shapes were not tried; KAN grid size (6) and spline order (3) were the frozen ones and not varied; M1 and its control were trained on 28 heads while the GRU/B2 were trained on 16 (main) or 12 (forecast), so M1-vs-GRU differences include a head-set difference (as in Stage 4); interpretability metrics use window-wide shifts (not single-feature interventions on the data-generating process), the shape metric is weakly discriminating, and the sensitivity ranking uses SD-normalised prediction ranges, not loss-based permutation importance (also stored in `sensitivity.csv`). The reproducibility check: seed-0 of the B2 MLP retrained from scratch gives a checkpoint identical to the saved one.
